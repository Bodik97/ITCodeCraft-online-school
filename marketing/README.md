# Маркетингові креативи

Брендовані рекламні зображення для ITCodeCraft (онлайн-школа програмування 7–17 років).
Згенеровано на дизайн-токенах сайту (неонові кольори, шрифти Outfit/Inter), факти реальні
(500+ учнів, рейтинг 4.9, безкоштовний перший урок).

| Файл | Розмір | Призначення |
|------|--------|-------------|
| `ig-post.jpg` | 1080×1080 | Пост/реклама в Instagram та Facebook (квадрат) |
| `ig-story.jpg` | 1080×1920 | Stories / Reels Instagram та Facebook (вертикаль) |

OG-картинку для прев'ю посилань у соцмережах оновлено окремо:
`public/assets/OGP/fb.png` і `tw.png` (1200×630) — підставляються автоматично через мета-теги.

> Щоб оновити креативи — відредагуйте шаблон і перегенеруйте через ckm-design (banner workflow).
