# Функціональне тестування сторінки

## 1. Підготовка
- Dev-сервер Astro на http://localhost:4321/ (`npm run dev`; не запускай другий, якщо вже працює).
- Звіти — у scratchpad/тимчасову теку, не в репозиторій.

## 2. Автоматичний прогін
```bash
node .claude/skills/page-functional-test/scripts/functional.mjs --url http://localhost:4321/ --out <тека>
```
Кожен крок друкується як ✓/✗, підсумок — у `<тека>/functional.json`. Код виходу 1, якщо є провали.

**Безпека даних:** скрипт перехоплює всі POST/PUT/PATCH на зовнішні домени й повертає фейкову відповідь — справжні заявки в CRM не потрапляють. Ніколи не відправляй форму з реальними даними поза цим скриптом. Якщо тестуєш вручну через Playwright MCP — заповнюй лише невалідні дані або не натискай «Записатись».

Покриття (десктоп 1440 + мобільний 390):
- якорі меню → існуючі секції; липка шапка
- модалка запису: відкриття CTA, назва курсу в заголовку, закриття Escape і ×
- форма: помилки при порожній відправці, невалідний email
- каруселі `#courses`, `#reviews`: стрілки, стан «назад», пагінація
- FAQ `<details>`; відеомодалка робіт (YouTube src з'являється і скидається при закритті)
- рядок напрямків у hero змінюється; лічильники доходять до значень
- JSON-LD парситься; внутрішні посилання 200; `target=_blank` з `noopener`
- перший Tab дає видимий фокус; помилки консолі
- мобільне меню (aria-expanded, закриття по кліку), липка CTA, перекриття футера, горизонтальна прокрутка

## 3. Ручні сценарії (доповни, яких немає в скрипті)
Через Playwright MCP або власний Playwright-скрипт:
- Tab-навігація по всій сторінці: порядок логічний, фокус не губиться в закритому меню/модалці, у відкритій модалці фокус не тікає назад на сторінку.
- Модалка: прокрутка сторінки під нею заблокована; після закриття фокус повертається на кнопку, що її відкрила.
- Телефонне поле: вибір країни, маска, повідомлення про помилку.
- `prefers-reduced-motion: reduce` — анімації вимкнені, контент видно.
- Повільна мережа / вимкнені картинки — макет не розвалюється.
- Посилання на лендинги `/roblox`, `/minecraft`, `/frontend`, `/scratch` відкриваються.
